# Tehtavalista
Harjoitusprojekti: GitHub ja Claude Code

## Mikä tämä on?
Yksinkertainen tehtävälista verkkosivuna. Tehtäviä voi lisätä, merkitä tehdyiksi ja poistaa.
Tehtävät tallentuvat omaan selaimeen (localStorage), joten mitään palvelinta ei tarvita.

## Tila
Sovellusta ei ole vielä tehty. Tämä README on ensimmäinen Claude Coden tekemä muutos.
